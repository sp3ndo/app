## 📱 Tentang Spendo App

Spendo App dikembangkan oleh Tim IT SMPN 2 Doko sebagai jembatan komunikasi digital antara pihak sekolah dengan orang tua atau wali murid. Seluruh transmisi data terhubung langsung ke server mandiri sekolah secara aman, bebas iklan komersial, dan 100% gratis.

### ✨ Fitur Utama Aplikasi

1. **Presensi Gerbang Sekolah Real-Time**
   - Notifikasi kedatangan dan kepulangan siswa terkirim langsung ke smartphone orang tua saat kartu pelajar ditap pada gerbang sekolah.
   - Rekapitulasi persentase kehadiran bulanan, status tepat waktu, sakit, dan izin.

2. **e-Rapor Kurikulum Merdeka**
   - Akses transparan laporan hasil belajar dan capaian kompetensi per mata pelajaran.
   - Portofolio penilaian sumatif dan formatif berkala tanpa menunggu pembagian rapor fisik semesteran.

3. **Buku Ketertiban & Pengumuman Digital**
   - Pemantauan catatan kedisiplinan dan poin tata tertib siswa secara berkala.
   - Saluran pengumuman resmi agenda akademik, kegiatan sekolah, dan kalender pendidikan.

## 📥 Cara Mengunduh & Memasang

### Opsi A: Melalui Portal Web Resmi (Direkomendasikan)
Kunjungi portal unduhan resmi di **[apk.s2d.sch.id](https://apk.s2d.sch.id)** dari browser ponsel Android Anda, lalu tekan tombol **"Instal Aplikasi"**.

### Opsi B: Langsung dari Repositori GitHub Ini
1. Buka tab **[Releases](https://github.com/OWNER/REPO/releases)** di repositori ini.
2. Cari rilis dengan label **Latest**.
3. Pada bagian **Assets**, ketuk berkas `Spendo-App-v1.0.0.apk` untuk langsung mengunduh biner instalasi.

---

## ⚙️ Petunjuk Pemasangan di Ponsel Android

Karena Spendo App didistribusikan secara mandiri oleh server lokal sekolah:

1. **Unduh Berkas:** Jika muncul notifikasi browser *"File mungkin berbahaya"*, pilih **"Tetap unduh"** (prosedur keamanan standar Android untuk unduhan APK di luar Google Play Store).
2. **Izin Sumber Aplikasi:** Buka berkas yang baru diunduh. Jika muncul dialog perizinan sistem, buka **Setelan** dan aktifkan sakelar **"Izinkan dari sumber ini"**.
3. **Selesaikan Instalasi:** Ketuk tombol **"Pasang"** atau **"Instal"**, lalu buka aplikasi dan masuk menggunakan akun resmi dari sekolah.
